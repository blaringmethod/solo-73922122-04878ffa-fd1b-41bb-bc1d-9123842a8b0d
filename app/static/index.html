查看公开页 →

1. 导入调查数据

CSV 表头：分区,年龄组,人数,检出数。至多 16 格；人数 ≥ 5；检出数为 0~人数的整数；（分区,年龄组）组合唯一。导入后不可更换。

2. 原始数据（仅内部可见，公开页不含格内检出数）

3. 选择发布范围并预览 / 发布

4. 已公开记录（不可撤销）

5. 核对公开汇总（按分区 / 年龄组复核合计）

填写覆盖所有分区、所有年龄组的两组复核检出合计（整数），并选择一条公开记录。 修订后的各格检出数仍须在 0~人数之间；在满足两组合计且改动格数最少的所有可行修订中， 标出每次都要改的格与仅部分修订会改的格，并给出所选公开合计的可行上下界。 历史公开总数仅作对照，不约束修订；核对为只读操作，不改动调查数据与公开记录。
